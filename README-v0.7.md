# PetAlyze MVP v0.7 — Product Integration

This patch turns the existing modules into a connected product flow.

## Added
- richer Dashboard
- latest Journal memory on Dashboard
- latest AI Story on Dashboard
- upcoming vaccination reminder on Dashboard
- Journal → AI Story action
- automatic pet + memory prefilling in AI Story
- language selector in AI Story UI
- direct links between Dashboard, Journal, AI Story, Story Library and Pet Passport

## No database migration required
v0.7 uses the existing Supabase tables from v0.3-v0.6.
