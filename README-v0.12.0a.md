# PetAlyze v0.12.0a — Public Website Refresh

Updates the public landing page to match the actual PetAlyze MVP and approved pricing.

Changes:
- Replaces obsolete Free/Premium $7 pricing with Free / Plus / Pro.
- Shows 30 / 400 / 800 monthly AI-credit allowances.
- Describes the working MVP: pet profile, Journal, Passport, Media Library, AI Stories, AI Illustrations and AI Comics.
- Adds clear digital-service positioning.
- Adds a careful social-content section explaining that users can publish PetAlyze-created content on third-party social platforms and may monetize there if eligible under those platforms' rules; PetAlyze does not promise earnings.
- Removes the public demo-dashboard CTA.
- Makes clear that paid checkout is not enabled yet.
- Keeps registration as the primary CTA.

No SQL and no environment-variable changes are required.

Install: copy this patch over the current PetAlyze project and replace matching files.
Then run `npm run dev` and check the home page.
